## المرحلة 0 — الاستكشاف ✅
- فحص البيئة: Python 3.12، Node 24، pnpm، uv، Docker، Git.
- **التحقق:** مثبت في PROGRESS.md.

## المرحلة 1 — التصميم الهندسي
- الوثائق: README، PRODUCT_REQUIREMENTS، ARCHITECTURE، DATABASE_SCHEMA، API_CONTRACT، SECURITY_MODEL، DECISIONS.
- **التحقق:** كل نموذج في DATABASE_SCHEMA موجود فعلياً في الكود (بعد المرحلة 3).

## المرحلة 2 — التأسيس
| المهمة | التحقق |
|---|---|
| docker-compose: postgres 16، redis 7، minio | `docker compose up -d` وفحص الصحة |
| Django 5.2 + DRF + spectacular + settings متعددة | `manage.py check --deploy` (prod) بدون أخطاء حرجة |
| pytest + ruff | `pytest` و`ruff check` ينجحان |
| Next.js 16 + Tailwind 4 + نظام التصميم | `pnpm build` ينجح |
| packages/api-client من OpenAPI | `pnpm gen:api` يولد الأنواع |
| Expo app | `expo export` أو تشغيل Metro |

## المرحلة 3 — النظام الأساسي (Backend أولاً، ثم الويب)
1. الحسابات وتسجيل الدخول (جلسة + توكن) — اختبارات: نجاح وفشل وقفل وتسجيل خروج.
2. المنشآت والعضويات والأطباء والتحقق — اختبارات: طبيب غير معتمد لا يكتب سجلات.
3. المرضى والبطاقة والتسجيل والتكرار — اختبارات: الرقم الصحي فريد وبرقم تحقق، البطاقة قابلة للإبطال.
4. محرك الصلاحيات والموافقات — اختبارات العزل (أهم مجموعة اختبارات).
5. السجلات: الزيارة، والتشخيص، والحساسية، والتصحيح الموثق.
6. الأدوية والمفضلة والقوالب والوصفة والطباعة والتحقق العام.
7. المستندات: الرفع والتنزيل الموقع.
8. التحاليل: الطلب، والتقرير، والنتائج، والاعتماد.
9. التدقيق ورؤية المريض لسجل الوصول.
10. واجهات الويب: عامة، وطبيب، واستقبال، ومختبر، ومريض، ومدير منشأة، ومدير منصة.
11. **اختبار القبول:** سيناريو الـ20 خطوة كاختبار API آلي (`tests/test_acceptance_scenario.py`) + اختبار E2E بـPlaywright للمسار الأساسي.

## المرحلة 4 — تطبيق الموبايل
تسجيل الدخول ← البطاقة الصحية (QR) ← السجل الزمني ← الوصفات ← التحاليل ← المستندات ← الموافقات ← الإشعارات. ثم واجهة الطبيب: مسح QR وفتح الملف وملاحظة سريعة.

## المرحلة 5 — الإضافات
الإحالات الكاملة، وOCR بواجهة مزود + مراجعة بشرية، ورسم بياني للنتائج عبر الزمن، والإشعارات اللحظية، وDICOM (Orthanc + OHIF).

## المرحلة 6 — ما قبل الإنتاج
مراجعة أمنية، واختبار اختراق للعزل، والنسخ الاحتياطي والاستعادة، وتوثيق النشر، والقائمة القانونية (SECURITY_MODEL §11).
