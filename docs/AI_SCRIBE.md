# HayatTek AI — المساعد الطبي الذكي

> المصدر: `requirements/PHASE2_REQUIREMENTS.md` §12–§18. الكود: `backend/apps/scribe/`، الواجهة: `apps/web/src/components/scribe/` و`/app/encounters/<id>/scribe/<session>`.
> **الحالة: يعمل محلياً بمزود تجريبي (Mock) وتسجيلات اصطناعية. غير مسموح باستخدامه مع مرضى حقيقيين** قبل اعتماد مزود حقيقي قانونياً وترتيبات الخصوصية (انظر `AI_PROVIDER_EVALUATION.md`).

## سير العمل
```
الطبيب يفتح مسودة زيارة → اختيار «الاستماع الذكي» (حوار) أو «الإملاء الذكي»
→ (الحوار) تسجيل موافقة المريض: شفهية/مكتوبة — بدونها لا يبدأ التسجيل
→ تسجيل WAV في المتصفح مع مؤشر أحمر وعداد، إيقاف مؤقت/استئناف
→ «إنهاء وتحليل» → رفع آمن → تخزين مشفّر → مهمة خلفية
→ تفريغ الصوت (SpeechToTextProvider) → استخراج منظم (ClinicalExtractionProvider)
→ مسودة جاهزة (هنا تُحتسب الرسوم مرة واحدة) → صفحة المراجعة
→ الطبيب يقارن بالنص الأصلي، يعدّل، يختار ما يُضاف → «تطبيق على الزيارة»
→ تُحدّث مسودة الزيارة + تشخيصات/حساسيات كمسودات + وصفة **مسودة** + طلبات تحليل/تصوير
→ الطبيب يعتمد الزيارة (اختيارياً مباشرة) والوصفة من محررها كالمعتاد
```

## مبادئ الاستخراج (مُطبقة ومختبرة)
| المبدأ | التطبيق |
|---|---|
| لا اختراع | لا تشخيص أو دواء أو جرعة لم تُذكر؛ الجرعة الغائبة تبقى فارغة مع «لم تُذكر الجرعة». |
| كلام المريض ≠ تقييم الطبيب | التشخيصات تُستخرج من مقاطع الطبيب فقط (أو المتحدث المجهول مع تنبيه). |
| العبارات غير المؤكدة | «غالباً، ممكن، احتمال، اشتباه…» ← `suspected` وتظهر «مشتبه — ليس تشخيصاً نهائياً». |
| الأدوية غير الواضحة | دواء غير معروف الاسم أو خارج الكتالوج ← `needs_review` مع السبب، وغير محدد افتراضياً في المراجعة. |
| المتحدث غير المؤكد | يظهر «متحدث غير محدد» وتحذير عام. |
| ربط المصدر | كل حقل يحمل `sources` (معرفات المقاطع)؛ تمرير المؤشر يُبرز الجملة الأصلية. |
| مسؤولية الطبيب | الملاحظة المضافة للزيارة: «أُعدّت بمساعدة HayatTek AI وراجعها واعتمدها د. …»، والسجل باسم الطبيب. |
| الوصفة | لا تُعتمد تلقائياً أبداً: تُنشأ مسودة ويكملها الطبيب. |

## اللهجة السورية
محرك الاستخراج المحلي (`extraction.py`) يتعامل مع: الأعداد المنطوقة («مية وخمسين على تسعين»، «تمانية وتلاتين ونص»، «لألف»)، الأرقام العربية الهندية، توحيد الهمزات والتاء المربوطة، تعابير شامية («صرلي، عم آخد، بوصفلك، راجعني»)، أسماء أدوية عربية/إنجليزية مختلطة («الـ Metformin»).
**تنبيه:** هذا يقيس الاستخراج من نص مكتوب. دقة **التفريغ الصوتي** للهجة السورية لم تُقس بعد لأن المزود الحقيقي غير معتمد (انظر خطة التقييم في `AI_PROVIDER_EVALUATION.md`).

مجموعة التقييم الاصطناعية: `apps/scribe/samples.py` (3 حالات: حوار ألم صدري بلهجة سورية مع دواء مجهول وحساسية، إملاء سكري مختلط عربي/إنجليزي، سعال طفل بدواء دون جرعة) — جميعها تنجح في `tests/test_scribe.py::test_extraction_matches_expected`.

## الخصوصية والأمان
| المتطلب | التنفيذ |
|---|---|
| موافقة المريض | إلزامية للحوار (قيد في قاعدة البيانات `conversation_requires_patient_consent` + فحص في الخدمة). الإملاء لا يسجل المريض. |
| مؤشر تسجيل واضح / منع التسجيل الخفي | التسجيل يبدأ فقط بضغطة الطبيب، مؤشر أحمر نابض وعداد، والمتصفح يعرض أيقونة الميكروفون. |
| التشفير | الصوت مشفّر قبل التخزين (Fernet: AES-128-CBC + HMAC-SHA256) بمفتاح `HAYAT_AI_AUDIO_KEY` (إلزامي خارج التطوير) في مخزن خاص. |
| الاحتفاظ والحذف | `retention_until` (افتراضياً 30 يوماً، `HAYAT_AI_AUDIO_RETENTION_DAYS`) + مهمة يومية `purge_expired_audio` + حذف فوري من الطبيب أو عند إلغاء الجلسة. المدة النهائية قرار قانوني. |
| الوصول | مؤلف الجلسة فقط وفي نفس المنشأة. لا الزملاء ولا مدير المنصة ولا المريض (الـendpoint يتطلب طبيباً معتمداً). |
| السجلات | لا صوت ولا نص طبي في الـLogs؛ أحداث التدقيق: `scribe.start/upload/view/ready/failed/retry/approve/audio_played/audio_deleted`. |
| رفض التسجيل | الإدخال اليدوي يبقى متاحاً دائماً؛ الخدمة اختيارية. |
| المزود الحقيقي | `_load()` يرفض تحميل أي مزود `is_real` ما لم يُضبط `HAYAT_AI_REAL_PROVIDERS_APPROVED=true`. |

## المعالجة والفشل
- الحالات: `created → uploaded → processing → ready → approved` أو `failed` / `discarded`.
- المعالجة idempotent: تكرار المهمة لا يعيد المعالجة بعد `ready` ولا يكرر الفوترة؛ عامل آخر يعمل على نفس الجلسة يُتجاهل لمدة 10 دقائق.
- فشل المزود ← `failed` بلا رسوم + تسجيل تكلفتنا؛ «إعادة المحاولة» من الواجهة مجانية.
- التسجيل المقطوع (انقطاع أثناء الكتابة): يُقبل بمدته الحقيقية المحسوبة من البيانات الفعلية.
- المدة **تُحسب في الخادم** من ترويسة WAV وليس من الواجهة (أساس الفوترة).
- إيقاف الخدمة أثناء جلسة قيد المعالجة: تكتمل وتُفوتر مرة واحدة؛ يُمنع بدء جلسات جديدة فقط.

## واجهات المزود (للاستبدال لاحقاً)
`SpeechToTextProvider.transcribe()` → `TranscriptResult(segments[speaker,start,end,text], cost, cost_is_actual, diarization)`
`ClinicalExtractionProvider.extract()` → `ExtractionResult(fields, cost, warnings)`
الإعداد: `HAYAT_AI_STT_PROVIDER`, `HAYAT_AI_EXTRACTION_PROVIDER`, `HAYAT_AI_REAL_PROVIDERS_APPROVED`.

## التسجيلات الاختبارية
في التطوير والاختبار يظهر في اللوحة «تسجيل اختبار اصطناعي» (معطّل في الإنتاج). الصوت نغمات اصطناعية تحمل معرّف السيناريو؛ المزود التجريبي يعيد النص المكتوب للسيناريو. أي تسجيل حقيقي من الميكروفون مع المزود التجريبي يعيد نصاً تجريبياً عاماً **مع لافتة واضحة** أنه ليس تفريغاً لصوتك.
