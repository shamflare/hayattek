# متطلبات المنتج — حياة (HAYAT)

المصدر الكامل للرؤية: `info.md`. هذه الوثيقة تحوّلها إلى متطلبات قابلة للتحقق، مع ربط كل متطلب بمكان تنفيذه وطريقة اختباره.

## المستخدمون

| المستخدم | الهدف الأساسي | النجاح يعني |
|---|---|---|
| الطبيب | يرى المهم ويكتب الزيارة والوصفة بسرعة | فتح الملف + زيارة + وصفة مطبوعة في أقل من 3 دقائق |
| الاستقبال | يسجل المريض دون تكرار | ملف جديد خلال 60 ثانية، والمكررات تُكتشف |
| المختبر/الأشعة | يستقبل الطلبات ويصدر نتائج منظمة | النتيجة تصل للطبيب والمريض فور الاعتماد |
| المريض | يملك ملفه ويتحكم بمن يراه | يرى سجلاته، ويوافق أو يلغي الوصول، ويعرف من اطلع |
| مدير المنشأة | يدير فريقه وهوية الطباعة | دون أي وصول للسجلات الطبية |
| مدير المنصة | يفعّل المنشآت ويعتمد الأطباء | مؤشرات مجمّعة فقط، وسجل أمني |

## المتطلبات غير الوظيفية

| المجال | المتطلب |
|---|---|
| البساطة | لا حقول إجبارية غير ضرورية؛ أهم العمليات بنقرة أو نقرتين؛ بحث فوري (Ctrl+K) |
| اللغة | عربية افتراضياً RTL؛ بنية ترجمة قابلة للإنجليزية |
| الشبكة الضعيفة | استجابة ملخص المريض في طلب واحد؛ لا تحميل ملفات تلقائي؛ ترقيم السجل الزمني |
| الأمان | OWASP ASVS L2؛ فحص صلاحيات لكل سجل؛ MFA للحسابات الطبية في الإنتاج |
| الخصوصية | الأدوار الإدارية لا ترى السجلات؛ لا PHI في السجلات التقنية |
| التوقيت | تخزين UTC، عرض بتوقيت دمشق |

## خارج النطاق (الإصدار الأول)

المخزون والمحاسبة والتأمين والدفع، إدارة الأسرة، PACS كامل، تشخيص أو وصف آلي بالذكاء الاصطناعي، الدردشة، المزامنة دون اتصال للملفات الطبية.
