المتطلبات الكاملة كما وردت حرفياً: [`requirements/PHASE2_REQUIREMENTS.md`](requirements/PHASE2_REQUIREMENTS.md).
التقدم الفعلي: [`PROGRESS.md`](PROGRESS.md).

## القواعد الحاكمة (غير قابلة للتفاوض)

1. **لا إعادة بناء:** نطوّر المستودع الحالي؛ لا حذف لـmigrations أو بيانات أو اختبارات.
2. **المحفظة آجلة (Postpaid):** الرصيد يمكن أن يصبح سالباً بلا حد، و**لا يوجد أي مسار في الكود يوقف المساعد الذكي بسبب الدين**. الإيقاف يدوي فقط من Super Admin. التنبيهات معلوماتية فقط. يوجد اختبار يثبت الاستمرار عند دين 1,000 دولار.
3. **إشارة الرصيد:** موجب = رصيد دائن للطبيب، سالب = الطبيب مدين. الرصيد = الدفعات والأرصدة الدائنة − الرسوم والتسويات المدينة. Decimal فقط، ولا Float.
4. **دفتر قيود (Ledger):** لا حذف ولا تعديل لقيد مالي؛ التصحيح بعملية عكسية موثقة. الرصيد قابل لإعادة الحساب من القيود.
5. **الفوترة مرة واحدة:** قيد واحد لكل جلسة ناجحة (مفتاح idempotency + قيد UNIQUE في قاعدة البيانات)، ولا رسوم عند الفشل.
6. **الذكاء الاصطناعي لا يقرر:** لا تشخيص ولا دواء ولا جرعة لم تُذكر، وكل شيء يبقى مسودة حتى يعتمده الطبيب ويُنسب إليه.
7. **لا خدمات مدفوعة، ولا مفاتيح حقيقية، ولا بيانات مرضى حقيقية، ولا VPN، ولا نشر عام** دون موافقة المالك. نستخدم مزودات Mock أو محلية ونوثق الفجوة بصدق.
8. **لا ندّعي اكتمال ميزة دون اختبار يثبت عملها.** الواجهة الشكلية أو Mock API ليست ميزة إنتاجية.
